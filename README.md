# PRIME SMP

Professional PRIME SMP website for GitHub Pages.

## Upload this structure

```text
prime-smp/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── scene1.svg
    ├── scene2.svg
    ├── scene3.svg
    └── scene4.svg
```

### What each file does
- `index.html` — website content and structure.
- `style.css` — design, responsive layout and animations.
- `script.js` — interactions and buttons.
- `assets/` — four lightweight Minecraft-style visual scenes.
- `README.md` — setup guide.

### GitHub Pages
Go to **Settings → Pages → Deploy from a branch → main → /(root)** and save.
